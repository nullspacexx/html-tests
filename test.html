Проекты

Тут я хочу поделиться тестовыми проектами, которые я сделала за все время на гитхаб

  • Nginx Log Analyzer–Это простой, но мощный анализатор логов веб-сервера Nginx, написанный на Bash. Скрипт разбирает access.log, подсчитывает количество уникальных IP-адресов, частоту ответов с кодами ошибок, находит самые популярные запросы и многое другое.Ссылка.
  • Flask Log Analyzer—Веб-приложение на Flask для анализа логов веб-сервера Nginx. Позволяет загружать access.log и получать визуальный отчёт о работе сервера: количество запросов, IP-активность, ошибки, популярные пути и т.д. Удобно для тех, кто хочет анализировать логи без командной строки.Ссылка.
  • Flask Ci Cd App—Небольшое Flask-приложение, развёртываемое через полноценный CI/CD-пайплайн. Репозиторий включает автоматическую сборку Docker-образа, тестирование и автодеплой с помощью GitHub Actions. Идеален как пример автоматизированной доставки кода «от пуша до прода».Ссылка.
  • System Resource Monitor—Консольное приложение на Bash для мониторинга системных ресурсов в реальном времени. Отображает загрузку CPU, использование памяти, диска и сети. Подходит для админов, DevOps-специалистов и всех, кто хочет быстро отслеживать состояние системы без лишних инструментов.Ссылка.
  • Prometheus Grafana Monitoring—Инфраструктурный проект по мониторингу контейнеров Docker с использованием Prometheus и Grafana. Позволяет отслеживать метрики CPU, памяти, сети и статуса контейнеров в реальном времени. Подходит для DevOps и системных администраторов, которым нужно видеть, что происходит «под капотом».Ссылка.
